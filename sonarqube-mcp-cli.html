        03 · SonarQube Web API
        
Everything in SonarQube, scriptable

        
The Web API gives scripts, pipelines and internal portals the same access people have in the UI. The calls below are real: public projects on SonarQube Cloud and on next.sonarqube.com, Sonar's public SonarQube Server, answer without a token. For private projects, add -H "Authorization: Bearer $SONAR_TOKEN". Web API v2 is gradually replacing v1 as endpoints are deprecated and replaced. What you can reach depends on your edition or plan, your add-ons and the token's permissions.

        04 · Gitar API & MCP
        
Gitar, wired into your pipelines and your tools

        
Gitar's REST API lets pipelines onboard projects, check health and gate merges. Its review agents call tools on your own MCP servers, alongside the built-in integrations. Gitar is an MCP client: the documentation describes no Gitar MCP server for coding agents.
